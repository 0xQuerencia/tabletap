# Changelog

## 1.0.0rc1

- Personalized soft-tap calibration, near-miss inspector, per-device desk profiles, feedback and rollback.
- Searchable action presets, native state-aware toggles, sequential/parallel/conditional workflows.
- Searchable desktop gesture launcher and named profiles with menu-only mappings.
- Local OBS, Discord, Home Assistant, KDE, GNOME, VS Code and X integrations.
- Unified background listener and private Unix socket; attachable terminal dashboard.
- Portable action-profile packs with explicit trust, atomic config edits and backup.
- Release automation and hardware acceptance checklist.

This is a Linux release candidate. Hardware detection performance and optional desktop integrations require real-device validation.
